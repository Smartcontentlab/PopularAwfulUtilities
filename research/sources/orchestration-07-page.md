# Letta Documentation

The platform for building stateful agents

Letta agents learn from experience and improve with use. The Letta agent harness is fully [open source](https://github.com/letta-ai/letta-code) and builds on our lab’s [latest research](https://www.letta.com/research) in AI memory and continual learning.

Use Letta to create coding agents, personal assistants, AI coworkers, and stateful agents embedded in your own applications.

[Get started with Letta →](https://docs.letta.com/quickstart)

![Letta app](https://docs.letta.com/images/letta-agent-chat.png)![Letta app](https://docs.letta.com/images/letta-agent-chat-dark.png)

## Getting started

[Section titled “Getting started”](https://docs.letta.com/#getting-started)

New to Letta? Follow the [quickstart](https://docs.letta.com/quickstart) and chat with Tutor, or choose a path below.

### ”I want an AI coding assistant”

[Section titled “”I want an AI coding assistant””](https://docs.letta.com/#i-want-an-ai-coding-assistant)

Start with the [quickstart](https://docs.letta.com/quickstart), choose an [LLM provider](https://docs.letta.com/configuration/models), then explore [Skills](https://docs.letta.com/configuration/skills) and the [GitHub Action](https://docs.letta.com/platform/github-action).

### ”I want a personal assistant for work”

[Section titled “”I want a personal assistant for work””](https://docs.letta.com/#i-want-a-personal-assistant-for-work)

Use the [Letta app](https://docs.letta.com/platform/desktop-app) to work with local files, add integrations with [Skills](https://docs.letta.com/configuration/skills), and automate recurring tasks with [Schedules](https://docs.letta.com/configuration/schedules).

### ”I want an AI coworker in Slack, Telegram, or Discord”

[Section titled “”I want an AI coworker in Slack, Telegram, or Discord””](https://docs.letta.com/#i-want-an-ai-coworker-in-slack-telegram-or-discord)

Follow the [Channels guide](https://docs.letta.com/configuration/channels) to connect an agent, then use an [always-on computer](https://docs.letta.com/platform/computers/byom#always-on-cloud-vm-deployment) to keep it available.

### ”I want to automate recurring work”

[Section titled “”I want to automate recurring work””](https://docs.letta.com/#i-want-to-automate-recurring-work)

Explore [Schedules](https://docs.letta.com/configuration/schedules) for recurring prompts, [Skills](https://docs.letta.com/configuration/skills) for reusable workflows, and [Mods](https://docs.letta.com/configuration/mods) for extending the harness.

### ”I’m building an application with stateful agents”

[Section titled “”I’m building an application with stateful agents””](https://docs.letta.com/#im-building-an-application-with-stateful-agents)

Start with the [Letta Agent SDK](https://docs.letta.com/agent-sdk/quickstart), then choose between managed deployment with Letta Cloud or running the complete runtime yourself with the [Letta App Server](https://docs.letta.com/platform/app-server).
